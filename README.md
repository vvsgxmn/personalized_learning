# 基于SpringBoot+Vue3的个性化在线学习系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![ElementPlus](https://img.shields.io/badge/-ElementPlus-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) 

## 项目介绍

一个功能完善的个性化在线学习系统，面向学生、教师和管理员三种角色，提供智能化的在线学习体验。系统集成了AI学习助手，能根据学生的学习情况提供个性化推荐和辅导。

## 功能模块

- **课程管理**：支持课程的创建、编辑、章节管理，学生可浏览课程列表并进行报名学习
- **在线测验**：教师可创建测验和题目，学生在线答题并自动批改评分
- **作业系统**：教师布置作业，学生提交作业，教师在线批改打分
- **学习资源**：支持多种类型资源（文档、视频、音频等）的上传、预览和下载
- **学习统计**：可视化展示学习进度、成绩分布、课程完成度等数据
- **AI学习助手**：集成通义千问AI，提供智能学习辅导和问答
- **学习计划**：学生可制定个性化学习计划，跟踪执行进度
- **用户管理**：管理员可管理用户信息、角色权限和系统数据
- **分类管理**：管理员对课程分类进行维护

## 技术架构

- **后端**：Spring Boot 2.4.0 + MyBatis-Plus 3.4.1 + JWT 认证
- **前端**：Vue 3.5 + Element Plus 2.4 + Vite 7 + ECharts 6 + Pinia
- **数据库**：MySQL 8.0
